# IdeFunctionLab

## Cel

Program oblicza funkcję f(x) = 2x + 3.

## Uruchomienie

Polecenie: `dotnet run`
Przykład:
dla x = 4 wynik to f(4) = 11.
dla x = -2 wynik to f(-2) = -1.

## Sprawdzenie w IDE

- VS Code: wynik kompilacji - Build succeeded, uruchomienia f(4) = 11 i obserwacja debuggera
  - value - x [double] = 4,
  - result - result [double] = 11.

- Visual Studio: nie mozna uruchomić na macu

- Rider: wynik kompilacji - Build finished successfully, uruchomienia - f(4) = 11; process finished with exit code 0 i obserwacja debuggera:
  - value - x = {double} 4,
  - result - result = [double] 11.
